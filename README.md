# LuisaTesibizi2026

Sitio web (GitHub Pages) con los artículos de Luisa F. Meneses Fandiño para Tesibizi 2026.

**Ver el sitio:** https://manzanita2707.github.io/LuisaTesibizi2026/

## Estructura

```
index.html            Página principal
assets/css/           Estilos
assets/js/            Visor de PDF, menú y video
assets/img/           Portadas de los artículos
articulos/            PDFs de los artículos
```

## Añadir el video de YouTube

En `index.html`, busque `data-youtube-id=""` y pegue el identificador del video
(o el enlace completo de YouTube) entre las comillas:

```html
<div class="video-frame" data-youtube-id="https://www.youtube.com/watch?v=XXXXXXXXXXX" ...>
```
